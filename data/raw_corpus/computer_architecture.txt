Computer architecture defines the conceptual structure and functional behavior of computer hardware systems. In 1945, mathematician John von Neumann published a foundational report describing the Von Neumann architecture, which consists of a Central Processing Unit (CPU), memory, and input/output mechanisms sharing common address and data buses. The CPU is internally composed of an Arithmetic Logic Unit (ALU) for arithmetic and logical operations, a Control Unit (CU) for instruction sequencing, and internal processor registers. The memory hierarchy bridges the latency gap between CPU execution speed and secondary storage, structured hierarchically from fastest to slowest: registers, L1 cache, L2 cache, L3 cache, main memory (Dynamic RAM), and non-volatile storage devices like solid-state drives (SSDs). The fundamental instruction execution cycle comprises four sequential phases: Fetch, Decode, Execute, and Writeback. In processor instruction set design, Reduced Instruction Set Computers (RISC), such as ARM architecture, prioritize small sets of simple instructions executing in single cycles, whereas Complex Instruction Set Computers (CISC), such as x86, support variable-length instructions performing multi-step operations. Amdahl's Law is a fundamental formula in computer architecture that predicts the theoretical maximum speedup achievable through parallel processing.
