Machine learning (ML) is a branch of artificial intelligence focused on building algorithms that learn patterns from data to make predictions or decisions. Machine learning is primarily categorized into supervised learning, unsupervised learning, and reinforcement learning. Supervised learning uses labeled training datasets to learn mapping functions, commonly applied in classification and regression tasks. Common loss functions include Mean Squared Error (MSE) for regression and Cross-Entropy loss for classification. Optimization algorithms, particularly Gradient Descent and Stochastic Gradient Descent (SGD), iteratively update model weights to minimize loss based on learning rate hyperparameters. In deep learning, the backpropagation algorithm, popularized in 1986 by David Rumelhart, Geoffrey Hinton, and Ronald Williams, calculates gradients of the loss function across neural network layers using the chain rule of calculus. Overfitting occurs when a model learns noise from training data, which can be mitigated through regularization techniques such as L1 regularization (Lasso), L2 regularization (Ridge), and Dropout. In 2017, the Transformer architecture was introduced in the seminal research paper "Attention Is All You Need" by Ashish Vaswani and colleagues at Google, replacing recurrent networks with self-attention mechanisms for natural language processing tasks.
