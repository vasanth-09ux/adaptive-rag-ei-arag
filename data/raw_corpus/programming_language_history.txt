The history of high-level programming languages spans several decades of technological evolution. In 1957, John Backus and his team at IBM released Fortran (Formula Translation), widely recognized as the first high-level programming language designed for scientific and numerical computation. In 1958, John McCarthy created Lisp at the Massachusetts Institute of Technology (MIT), pioneering functional programming concepts and automatic garbage collection. Between 1969 and 1973, Dennis Ritchie developed the C programming language at Bell Labs, creating a structured imperative language that heavily influenced modern computing and operating systems like UNIX. In 1979, Bjarne Stroustrup began developing C++ at Bell Labs as an extension of C providing object-oriented programming with classes. Guido van Rossum designed Python in December 1989 at the Centrum Wiskunde & Informatica (CWI) in the Netherlands, releasing version 0.9.0 in February 1991 with a philosophy emphasizing code readability. In 1995, James Gosling and Sun Microsystems launched Java, implementing the "Write Once, Run Anywhere" principle via the Java Virtual Machine (JVM). In 2006, Graydon Hoare at Mozilla initiated the Rust programming language to provide memory safety and concurrency without garbage collection.
